# Sudoku Assignment

As part of NUS IT5005 26/27 Sem 1 assignment.

Deployment of a Streamlit Community Cloud application.

## To run locally

Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run sudoku_app.py
```
